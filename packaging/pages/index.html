TLP Panel

See what your laptop is doing with power — and change it, without a terminal.

Install on Debian or Ubuntu

Add the repository once, and updates arrive with the rest of your system.

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL -o /etc/apt/keyrings/tlp-panel.asc \
  https://timemrah.github.io/tlp-panel/apt/tlp-panel.asc

echo "deb [signed-by=/etc/apt/keyrings/tlp-panel.asc] \
https://timemrah.github.io/tlp-panel/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/tlp-panel.list

sudo apt update
sudo apt install tlp-panel

TLP itself comes with it if it is not installed yet.

Arch Linux

yay -S tlp-panel

A single package, no repository

Grab the .deb from the latest release and install it with sudo apt install ./tlp-panel_*_all.deb. You will have to repeat that for each update.

What it does

TLP has no interface. It is a set of rules applied at boot and whenever the power cable moves, and reading what it did means running tlp-stat as root. TLP Panel answers the questions people actually ask — how many watts am I burning, will this last the flight, why is the fan on — and puts the handful of settings worth changing next to the answers.

Controls the hardware cannot honour are detected and marked unsupported rather than silently doing nothing. The window never runs as root.
